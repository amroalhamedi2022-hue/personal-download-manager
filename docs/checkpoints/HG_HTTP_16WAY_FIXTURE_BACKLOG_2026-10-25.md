## Diagnosis and scoped repair
The loopback test fixture used unmodified Python 3.12 `ThreadingHTTPServer`, whose inherited `request_queue_size` is **5** (confirmed in Python stdlib and official [socketserver docs](https://docs.python.org/3.12/library/socketserver.html#socketserver.BaseServer.request_queue_size)). The fixture observed up to 110 concurrent Range sockets; the small pending-accept queue can reject connections during a burst, independently of HyperGet production retry policy. **This is a plausible contributing cause, not yet a proven root cause.** Add a test-only `BurstReadyHTTPServer` with `request_queue_size = 256` while retaining loopback binding, per-task pacing, strict 16-way observed overlap, exact SHA-256 verification, and 9 process metric CSV requirements. No downloader, retry count, HTTP protocol, settings, persistence, browser, dependency, or security change. Existing Python standard library used under PSF license; no copied third-party implementation.
