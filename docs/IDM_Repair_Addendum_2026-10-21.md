## ملاحظات تصحيحية غير قابلة للمحو

- E031 يثبت قتل Process فعليًا ثم HTTP Resume وSHA، فلا يستمر وصف P2-03 بأنه بلا اختبار قتل عملية.
- E025 تجربة مستخدم محلية محدودة، لا دليل مرور HTTPS/FTP/Internet عام. Run 63 كان 100/100؛ Run 64 فشل HLS واحدًا، ثم Run 68 نجح 103/103، وRun HLS المستهدف نجح ثلاث مرات (E035).
- RF02/RF03 لها أدلة نجاح خاصة بالـRetry والتخزين، لكنها لا تغلق C04/C07 أو أمن RF04–RF07.
- P3/UI بدأ جزئيًا في الكود (مثلاً Liquid)، فلا يصح عرضه «لم يبدأ إطلاقًا» ولا «اكتمل بالصورة».
- لا تقيس RAM من صورة Task Manager وحدها (256.6 MB للمجموعة مقابل 15.0 MB لـIDM نقطة مقارنة واحدة). Baseline وحده يقرر إجراءات M09.
- متطلبات Android P9 والميزات المؤجلة غير الملغاة تظل في المصفوفة لكن لا تمنع إصلاح نسخة Windows الأساسية الآن.
